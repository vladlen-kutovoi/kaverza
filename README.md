## Що вміє

| | |
| --- | --- |
| **Партії** | Дуель, командна гра та FFA — зі складами, персонажами та переможцем. Адмін може редагувати й видаляти гру. |
| **Рейтинг** | Ело перераховується одразу після гри, історія кожної зміни зберігається. |
| **Гравці** | Профіль із рейтингом, вінрейтом, графіком рейтингу та списком партій. |
| **Персонажі** | Статистика та матриця протистоянь: хто проти кого і з яким відсотком перемог. |
| **Акаунти** | Вхід за паролем, сесії в куках, адмін-панель для додавання персонажів. |
| **Рандомайзер** | Інструменти для випадкового визначення персонажа та мапи. |

## Як рахується рейтинг

Кожен стартує з **1500**, K-фактор — **20**.

- **Дуель** — звичайний Ело між двома гравцями.
- **Командна гра** — команди порівнюються за середнім рейтингом, зміна однакова для всіх у команді.
- **FFA** — переможець грає окремий «матч» проти кожного суперника, його зміни сумуються.

Якщо гру відредагували чи видалили, рейтинг перераховується для неї та всіх наступних ігор — по черзі, від рейтингу, з яким гравці підійшли до цієї гри. Попередні ігри не змінюються.

## Стек

**Nuxt 4** · **Vue 3** · **Tailwind 4** · **Drizzle ORM** + **PostgreSQL** · **Zod** · **argon2**

## Запуск

```bash
# 1. Залежності
npm install

# 2. Підключення до бази
echo 'DATABASE_URL=postgres://user:password@localhost:5432/unmatched' > .env

# 3. Міграції
npm run db

# 4. Дев-сервер на http://localhost:3000
npm run dev
```

Збірка продакшену — `npm run build`, перегляд зібраного — `npm run preview`.

## Структура

```
app/        Сторінки, компоненти, стилі (токени + файл на компонент)
server/     API-роути, схема бази, міграції, Ело та матриця протистоянь
shared/     Код, спільний для клієнта та сервера
```

## Оновлення

### 09.11.2026

- **Редагування гри** — на сторінці гри адмін бачить кнопку «Редагувати»: відкривається форма додавання гри, вже заповнена. Змінити можна тип, гравців, персонажів і переможця; дата та автор лишаються.
- **Видалення гри** — кнопка «Видалити» поруч, з підтвердженням.
- Після редагування чи видалення рейтинг перераховується для цієї та всіх наступних ігор, старіші ігри не чіпаються.

### 01.11.2026

- **Рандомайзер персонажа** (`/random/characters`) — жереб по колу з анімацією, кожен наступний персонаж тягнеться з тих, що лишились (по одному на гравця).
- **Рандомайзер мапи** (`/random/maps`) — випадкова мапа з I, II, XVI, XVII.
- В обох можна клікнути на варіант, щоб прибрати його з жеребу — вибір запам'ятовується в браузері.
- **Лоадер сторінок** — анімація «зіткнення карт» під час переходів між сторінками.
- **Шапка** — посилання на рандомайзери, кнопка «Додати гру» тепер окрема поруч із профілем.
